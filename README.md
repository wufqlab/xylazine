# wastewater epidemiology for drug use (xylazine)

this is the data and script to plot the temporal dynamics of measured xylazine in the four different wasteawter treatment plants, which serves the city of El Paso. Detailed information can be found in this paper: Joseph et al., ACS ES&T 2026 
(Cite this: ACS EST Water 2026, 6, 2, 946–953. https://doi.org/10.1021/acsestwater.5c01016)
